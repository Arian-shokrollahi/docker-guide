## اول env. چیه؟
ا-`.env` یک فایل متنی ساده است که داخلش متغیرها را به شکل `KEY=value` تعریف می‌کنی تا Docker Compose بتواند از آن‌ها استفاده کند.

### یه مثال ساده ببنید از ساختار پوشه پروژه +‌اینکه داخل فایل env. چی میزارن
```
project/
├── compose.yaml
└── .env
```

داخل `.env`:

```
DB_NAME=appdb
DB_USER=appuser
DB_PASSWORD=secret123
APP_ENV=production
```

بعد در `compose.yaml`:

```
services:
  backend:
    environment:
      APP_ENV: ${APP_ENV}
      DB_NAME: ${DB_NAME}
      DB_USER: ${DB_USER}
      DB_PASSWORD: ${DB_PASSWORD}
```

یعنی Compose این مسیر را طی می‌کند:

```
.env
  ↓
Docker Compose
  ↓
${VARIABLE}
  ↓
environment:
  ↓
Container
```
---

```dockercomposefile
services:

  backend:
    environment:
      APP_ENV: production
      DB_HOST: database
      DB_NAME: ${DB_NAME}
      DB_USER: ${DB_USER}
      DB_PASSWORD: ${DB_PASSWORD}

  database:
    image: postgres:16
    environment:
      POSTGRES_DB: ${DB_NAME}
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
```
- الان همونطور که مشاهده میکنید شما سه قسمت رو دارید که در data base و backend مشترکه و این ۳ قسمت درمورد اطلاعات بک انده که شما میاید این متغیر هارو درون فایلی به اسمه فایل env. تعریف میکنید و سپس توسطه <mark>variable substitution </mark> میاد میزاره اون متغیر هایی که در فایل  env. تعریف کردی رو در اونجاهایی که اون متغیر رو با variable substitution صدا زدی <mark> {var}$ </mark> 

---
### یه مثال واقعی

```
project/
├── compose.yaml
└── .env
```

داخل `.env` متغیرها را به شکل `KEY=value` تعریف می‌کنی:

```
DB_NAME=appdb
DB_USER=appuser
```

بعد داخل `compose.yaml` از Variable Substitution استفاده می‌کنی:

```
services:
  backend:
    environment:
      DB_NAME: ${DB_NAME}
      DB_USER: ${DB_USER}
```

ا-Docker Compose مقدار `${DB_NAME}` و `${DB_USER}` را از `.env` می‌خواند و جایگزین می‌کند.

یعنی:

```
.env
DB_NAME=appdb
      ↓
${DB_NAME}
      ↓
appdb
```

فقط عبارت دقیق‌تر اینه:

> فایل `.env` را معمولاً کنار `compose.yaml` قرار می‌دهیم، نه «داخل Compose». Compose آن را می‌خواند و مقادیرش را برای `${VARIABLE}`ها استفاده می‌کند.
