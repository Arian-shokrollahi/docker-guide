# بریم سراغه یه سناریو نسبتا سخت: تو یه این سناریو با چیا کار میکنیم و هدف از این سناریو چیه؟
- درون این سناریو با  nginx & flask & postgresql
- هدف پروژه : یه وب‌اپ ساده داریم که کاربر از طریق Nginx وارد میشه، Nginx درخواست رو به Flask می‌فرسته، و Flask به PostgreSQL وصل میشه.
معماری:

```
User
  ↓
Nginx
  ↓
Flask Backend
  ↓
PostgreSQL
  ↓
Named Volume
```
-  و این هم نمایی از متغیر ها و نمایی از ارتباط کوتا بین backend , data base
```
                    Docker Compose
                         |
          ┌──────────────┴──────────────┐
          ↓                             ↓

       backend                       database
       -------                       --------
APP_ENV=production              POSTGRES_DB=appdb
DEBUG=false                     POSTGRES_USER=appuser
DB_HOST=database                POSTGRES_PASSWORD=secret
DB_PORT=5432
DB_NAME=appdb
DB_USER=appuser
DB_PASSWORD=secret
PORT=5000

          |
          | connects to
          ↓

database:5432/appdb
```
