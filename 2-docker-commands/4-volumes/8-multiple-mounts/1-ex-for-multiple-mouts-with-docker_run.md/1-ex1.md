# مثال اول میخوایم ما یک سناریو بگیم و از رویه اون بریم جلو و من مراحلشو برم و کد اون داکری که ران میکنیم + اون قسمت هایی که مانت کردیم رو بهتون نشون بدم
---
## این سناریو ما 

```
Scenario: Multiple Mounts with docker run

هدف:
یک Nginx container بساز که همزمان از Bind Mount، Volume و tmpfs استفاده کند.

Container name:
  nginx-multi-mount

Image:
  nginx:latest

Mount 1 - Bind Mount:
  Host path:
    /root/nginx-config

  Container path:
    /etc/nginx/conf.d

  حالت:
    read-only

Mount 2 - Volume:
  Volume name:
    nginx-html-data

  Container path:
    /usr/share/nginx/html

Mount 3 - tmpfs:
  Container path:
    /var/cache/nginx

Port:
  8080:80

```

---
## حالا بریم سراغه درست کردن این سناریو 

```
docker run -d \
--name nginx-multi-mount \
--mount type=bind,source=/root/nginx-config,destination=/etc/nginx/conf.d,readonly \
--mount type=volume,source=nginx-html-data,destination=/usr/share/nginx/html \
--tmpfs /var/cache/nginx \
-p 8080:80 \
nginx:latest
```
---
### توضیح قسمت هایه مختلفش 
- 1-قسمت اول اومد اون دستور اجرا کانتینر رو زدم + اجرا در Back ground  با فلگ d-
- ۲-بعد اومد اسم کانتینر رو همون اسمی که گفته بود در سناریو گذاشتم با فلگ  name--
- ۳- بعد مانت اول رو انجام دادم که bind mount انجام دادم و فایل کانفیگ رو بایند مانت کردم به مسیر root/nginx/ در هاست سیستم خودم
- ۴-بعد مانت دوم رو انجام دادم که یه volume mount انجام دادم و اومدم usr/share/ngixn/html/ رو مانت کردم به داکر ولومم که گفتم در فولدر های قبلی به کمک :
'docker inspect -f '{{json .Mounts}}' container name |jq'
- میتونید اون محلی که volume دیتا رو در اونجا نگه میداره رو ببینید
- ۵-سپس هم مانت دوم رو امدم انجام دادم چون ماندگاری اون دیتا برام مهم نبود اون را tmpfs mount کردم
