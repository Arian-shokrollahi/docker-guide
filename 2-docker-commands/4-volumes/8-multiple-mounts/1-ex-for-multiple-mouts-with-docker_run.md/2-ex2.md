# سناریو دوم سناریو پایتونی + docker run + multiple mounts
---
## خوده سناریو
```
Scenario: Backend Multiple Mounts with docker run

Image:
python:3.12-slim

Container name:
backend-multi-mount

Mount 1 - Bind Mount:
Host path:
  /root/backend-config

Container path:
  /app/config

Mode:
  read-only

Mount 2 - Volume:
Volume name:
  backend-uploads

Container path:
  /app/uploads

Mount 3 - tmpfs:
Container path:
  /app/cache

Important:
برای tmpfs این بار از این مدل استفاده کن:
  --mount type=tmpfs

Port:
  5000:5000

Run mode:
  detached

Task:
یک دستور docker run بنویس که هر سه Mount را همزمان روی همین Container ایجاد کند.
---

```

---


### کد هایه سناریو

```

docker run -d \
--name backend-multi-mount \
--mount type=bind,source=/root/backend-config,destination=/app/config,readonly \
--mount type=volume,source=backend-uploads,destination=/app/uploads \
--mount type=tmpfs,destination=/app/cache \
-p 5000:5000 \
python:3.12-slim
