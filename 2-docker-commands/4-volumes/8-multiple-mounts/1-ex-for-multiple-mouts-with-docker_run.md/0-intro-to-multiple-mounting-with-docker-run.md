# چی قراره تو این فولدر  ببینیم ؟
- درون این فولدر قراره بریم سراغه مثال هایه multiple mount به کمک docker run 
- که به کمک docker run بریم مدل هایه مختلف مانت کردن رو bind volume tmpfs تست کنیم و ببینیم به چه صورت است و تسلط خودمون رو در قسمت مانت کردن با مدل docker run ببریم بالا

## چیزایی که باید تو این قسمت بلد باشید چیست ؟
- 1-باید بلد باشید درون این قسمت که کد ها طولانی است از line continuation استفاده کنید برایه خوانایی بالا  و راحت بودن خودتون
- ۲-سپس باید مفاهیم mounting volume bind tmpfs رو بلد باشید
- ۳-و باید فرایند ساخت container رو با docker run درک کرده باشید
