# چی قراره ببنیم تویه این فایل 
---
#### گفتیم ما قراره با داکر راه اندازه سرویس هامون رو ببریم به سمت راه اندازی سریع و در مسیر devops یکی از مهمترین skill ها اینه که همچی رو بهینه و کاری کنیم که در سریع ترین زمان ممکن راه اندازی شن و مدیریت خوبی روشون داشته باشیم .

- شما اگر قراره باشد docker run  رو بزنیم و همچی رو تک تک مانت کنید باید هر روز یه کاره تکراری رو بکنید ولی با یه compose file ساده میتونید بترکونید و دیگه نیازی نداشته باشید که تک تک مانت کنید.


- در این فایل قراره از مثال هایه ساده مانت تا پیشرفته در composefile.yaml استفاده کنیم و ببنید که چقد compose file کاره شما رو در راه اندازی سرویس هاتون راحت میکند
