#  مدل هایه مختلفه دستور docker run -p + درک 0.0.0.0

---

	<img src="../../00-images/docker-pmodel.png" alt="" width=1000>
</p>

وقتی در Docker یا شبکه با چیزی مثل:

```text
0.0.0.0:8080->80/tcp
```

مواجه می‌شوی، معنی **0.0.0.0** این است:

> روی **همه Interfaceهای شبکه این سیستم** گوش بده (Listen کن).

یعنی Docker این Port را فقط روی یک IP خاص باز نکرده، بلکه روی تمام IPهای قابل دسترس سیستم Bind کرده است.

---

مثال:

```bash
docker run -d -p 8080:80 nginx
```

بعد:

```bash
docker ps
```

ممکن است ببینی:

```text
PORTS
0.0.0.0:8080->80/tcp
```

یعنی:

```text
Host Machine
     |
     |
Port 8080
     |
     ↓
Docker Container
     |
     |
Port 80
```

حالا اگر سیستم تو IPهای زیر را داشته باشد:

```
127.0.0.1
192.168.1.20
10.0.0.5
```

همه این‌ها می‌توانند به Port 8080 وصل شوند:

```
localhost:8080
192.168.1.20:8080
10.0.0.5:8080
```

---

مقایسه:

### حالت 1:

```bash
docker run -p 8080:80 nginx
```

معمولاً:

```
0.0.0.0:8080->80
```

یعنی همه IPها.

---

### حالت 2:

```bash
docker run -p 127.0.0.1:8080:80 nginx
```

اینجا فقط خود همان سیستم:

```
localhost:8080
```

دسترسی دارد.

کامپیوترهای دیگر شبکه نمی‌توانند وصل شوند.

---

در IPv6 هم مشابه آن داریم:

```
:::8080->80
```

یعنی روی همه آدرس‌های IPv6.

---

پس در ذهن داشته باش:

```
0.0.0.0 = همه آدرس‌های IPv4 این ماشین
127.0.0.1 = فقط خود ماشین (localhost)
IP مشخص مثل 192.168.1.10 = فقط همان کارت شبکه
```

در Docker وقتی می‌بینی:

```text
0.0.0.0:8080->80
```

یعنی Docker یک Port Forward ساخته که درخواست‌های ورودی به Port 8080 سیستم را به Port 80 داخل Container می‌فرستد.
