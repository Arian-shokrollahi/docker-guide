### خیلی جاها میبینید که درون فولدر پروژتون یک فایل دارید به اسمه فایل نیازمندی ها requirements.txt چرا این فایل رو میبینیم
---
#### شما تصور کنید در داکر فایل ۱۰ تا وابستگی (dependency) دارد یه برنامه باید ۱۰ تا خط بنویسید ولی میاید یه فایل مینویسید و در هر خط اسم اون وابستگی یا نیازمندی برنامه رو مینویسید و دیگه نیاز به طولانی تر کردن کد نیست
---

۱-`requirements.txt` لیست dependencyهای پروژه Python رو نگه می‌داره.  
۲-به‌جای اینکه داخل Dockerfile تک‌تک بنویسی:

```dockerfile
RUN pip install flask
RUN pip install requests
RUN pip install psycopg2
```

می‌نویسی داخل `requirements.txt`:

```text
flask
requests
psycopg2
```

۳-بعد فقط یک دستور در Dockerfile داری:

```dockerfile
RUN pip install -r requirements.txt
```

۴-`pip` فایل رو می‌خونه و همه پکیج‌های داخلش رو نصب می‌کنه.

پس بله، مزیتش اینه که dependencyها مرتب، قابل مدیریت و قابل تکرار می‌شن و Dockerfile هم شلوغ نمی‌شه.

---
ما همیشه گفتیم مهمترین چیز سادگی سرعت بالا و خواناتر بودن این منطقه فایل نیازمندی ها در پوشه پروژه بهتون کمک زیادی میکنه
