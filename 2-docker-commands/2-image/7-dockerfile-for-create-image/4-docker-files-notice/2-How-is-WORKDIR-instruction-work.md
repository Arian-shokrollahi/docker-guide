# اون مسیری که در جلو instruction WORKDIR میزاری اگر بود میره توش نبود میسازه میره توش 

## و مثلا میزنی . . COPY  داری میگی از سورس که پوشه پروژه فعلیت است کپی کن درون اون مسیری که با WORKDIR رفتی توش
---

```
WORKDIR /app
```

یعنی:

۱-اگر `/app` داخل image وجود داشته باشد، Docker می‌رود داخل همان مسیر.  
۲-اگر `/app` وجود نداشته باشد، Docker آن را می‌سازد.  
۳-بعد از آن، مسیر کاری فعلی می‌شود `/app`.  
۴-دستورهای بعدی مثل `COPY`، `RUN` و `CMD` معمولاً نسبت به همین مسیر کار می‌کنند.

مثلاً:

```
WORKDIR /app
COPY app.py .
```

یعنی:

```
/app ساخته یا انتخاب می‌شود
↓
app.py داخل /app کپی می‌شود
```

پس بله، برداشتت کاملاً درسته.
