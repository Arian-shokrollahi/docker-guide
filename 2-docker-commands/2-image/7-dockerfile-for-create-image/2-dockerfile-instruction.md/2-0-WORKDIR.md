## در این فایل به این میپردازیم که دستورالعمل WORKDIR چیست و چرا استفاده میشه و در کدام خط میاد و فرقش با CD  چیست

---
## WORKDIR Instruction

**ساختار:**

```
WORKDIR path
```

**جایگاه در Dockerfile:**

معمولاً بعد از `FROM` می‌آید، چون اول باید Base Image مشخص شود، بعد مسیر کاری داخل آن را تعیین کنیم.

مثال:

```
FROM node:20

WORKDIR /app
```

---


**کاربرد:**

ا-`WORKDIR` مسیر کاری پیش‌فرض داخل Image/Container را مشخص می‌کند.

یعنی به Docker می‌گوید:

«از این به بعد دستورهای بعدی را داخل این پوشه اجرا کن.»

مثلاً:

```
FROM node:20

WORKDIR /app

COPY package.json .

RUN npm install
```

اینجا:

1. از Node شروع کن.
2. برو داخل مسیر `/app`.
3. فایل `package.json` را داخل `/app` کپی کن.
4. دستور `npm install` را داخل `/app` اجرا کن.
---

## ا-WORKDIR چیست خیلی ساده؟

فرض کن یک اتاق خالی داری (همان Image پایه).

با `WORKDIR` به Docker می‌گویی:

**«برو داخل این پوشه و از اینجا کار کن.»**

مثلاً:

```
FROM node:20

WORKDIR /app
```

یعنی:

1. یک محیط Node آماده بردار.
2. داخل آن یک پوشه به اسم `app` بساز و برو داخلش.

حالا هر کاری بعدش بگویی، داخل همان پوشه انجام می‌شود.

مثلاً:

```
COPY server.js .
```

یعنی:

«فایل `server.js` را همین‌جایی که الان هستم کپی کن.»

که می‌شود:

```
app
 └── server.js
```

یا:

```
RUN npm install
```

یعنی:

«دستور نصب را داخل پوشه app اجرا کن.»

---

اگر خیلی خلاصه بخواهیم:

ا-**WORKDIR یعنی انتخاب کردن محل کار داخل Image.**

مثل وقتی وارد یک فولدر در کامپیوتر می‌شوی و می‌گویی:  
«از اینجا به بعد فایل‌ها را اینجا بساز و تغییر بده.»

---
## این که مثل دستور  cd است فرقشون چیه پس


فرق ساده:

### `cd`

یک دستور **موقت در Shell** است.

مثلاً:

```
cd /app
npm install
```

یعنی:

- برو داخل `/app`
- بعد `npm install` را اجرا کن

اما این تغییر مسیر فقط در همان محیطی که دستور را زدی باقی می‌ماند.

---

### `WORKDIR`

یک **دستور مخصوص Dockerfile** است که مسیر کاری را برای ادامه ساخت Image مشخص می‌کند.

مثلاً:

```
FROM node:20

WORKDIR /app

COPY package.json .

RUN npm install
```

ا-Docker بعد از `WORKDIR` می‌داند که:

- ا-`COPY` داخل `/app` انجام شود
- ا-`RUN` داخل `/app` اجرا شود
- دستورهای بعدی هم از همین مسیر استفاده کنند

---

اگر بخواهیم با `cd` بنویسیم، مجبور می‌شدیم:

```
FROM node:20

RUN cd /app && npm install
```

ولی مشکل اینجاست که هر `RUN` یک مرحله جداست؛ یعنی:

```
RUN cd /app
RUN npm install
```

کار نمی‌کند، چون `cd` در خط اول برای خط بعدی باقی نمی‌ماند.

پس:

- ا-`cd` → تغییر مسیر موقت داخل یک دستور
- ا-`WORKDIR` → تعیین مسیر کاری دائمی برای کل مراحل بعدی Dockerfile

به زبان خیلی ساده:

ا-**`cd` یعنی "الان برو آنجا".**  
ا-**`WORKDIR` یعنی "از اینجا به بعد محل کار من اینجاست".**
