# بریم سراغه دستورالعمل ENV--->environment variable

---
### دستورالعمل ENV داخله داکر فایل چیکار میکند:
- دستورالعمل ENV داخل داکر فایل برایه اینه که بتونید داخل اون کانتنری که از ایمیج ران میشه متغیر محیطی داشته باشید یعنی یک مقدار رو با اسم ذخیره کنی تا برنامه داخله داکر بتونه ازش استفاده کنه:
```
ENV APP_NAME=myapp
ENV APP_ENV=production
ENV PORT=5000
```
- بعد داخل کانتینر اگر از این کلید هایه متغیر هایی که تعریف کردید echo بگیرید میبینید که مقداری برایه اون ها وجود دارد یعنی با داکر فایل که درست کردیم در اون خطی که متغیر محیطی تعریف کردیم اون متغیر محیطی رفته تو کانتینر و کانتینر میتونه از مقدارش استفاده کنه
```
echo $APP_NAME
echo $APP_ENV
echo $PORT
```
