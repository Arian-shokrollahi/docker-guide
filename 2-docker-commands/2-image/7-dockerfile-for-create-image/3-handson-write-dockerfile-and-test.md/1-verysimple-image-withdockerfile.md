### سناریو نوشتن داکر فایل سطح خیلی مبتدی
---
هدف این سناریو خیلی ساده و پایه‌ایه: می‌خوای مطمئن بشی منطق اصلی Dockerfile رو فهمیدی، نه اینکه فقط دستورها رو حفظ کردی.

در این تمرین می‌خوای یاد بگیری:

- ا-`FROM` یعنی image پایه‌ات چیه.
- ا-`COPY` یعنی چطور یک فایل از سیستم خودت وارد image کنی.
- ا-`CMD` یعنی وقتی container اجرا شد، چه دستوری اجرا بشه.

هدف نهایی اینه که وقتی بزنی:

```
docker run simple-image
```

خروجی بگیری:

```
Hello Docker
```

این تمرین عمداً ساده است تا فقط این مفهوم جا بیفتد:

**چطور فایل‌های پروژه را داخل Image می‌بری و مشخص می‌کنی Container موقع اجرا چه کاری انجام دهد.**

---
### خوده سناریو

سناریو:

ساختار پروژه:

```
simple-dockerfile/
├── Dockerfile
└── hello.txt
```

داخل `hello.txt` بنویس:

```
Hello Docker
```

وظیفه تو اینه Dockerfileای بنویسی که:

- از `ubuntu` استفاده کنه
- فایل `hello.txt` رو داخل image کپی کنه
- وقتی container اجرا شد، محتوای فایل رو نمایش بده

فقط از این‌ها استفاده کن:

```
FROM
COPY
CMD
```

### بریم سراغه انجام این سناریو
- 1- خب در این سناریو اول نیاز به پوشه پروژ رویه سیستم خودمون (host) داریم که ما میایم پوشه ای میسازیم به اسم  simple-dockerfile
- 2-حالا درون اون باید یه فایل بزاریم که قراره در قسمت دستورالعمل داکر فایل خوانده و در در ایمیج ما کپی شه به اسمه hello.txt
- ۳- حالا نیاز داریم به داکر فایلی که با دستورالعمل هایی که درونشون مینویسیم بتونیم image رو درست کنیم به اسم Docker file درون پوشه پروژمون
- ۴-حالا با ویرایش گر متنمون که من vim  رو انتخاب کردم میریم تو فایل داکر فایل vim Docker file
- و این دستورالعمل ها و ارگومان هارو مینوسیسم 
```bash
FROM ubuntu
COPY hello.txt .
CMD ["cat", "hello.txt"]
```
۵-سپس که این کد هارو نوشتیم میریم سراغه ساختن build کردن اون image

```
docker build -t simple-image .
```
- ۱-docker که دستور داکره
- ۲-build برایه ساختن ایمیج از رویه docker file استفاده میشه
- ۳-t- فلگ t- برایه درست کردن تگ برایه اون image
- ۴- . یعنی در همین دایرکتوری

### حالا بریم سراغه توضیح داکر فایل که نوشتیم

```
FROM ubuntu
COPY hello.txt .
CMD ["cat", "hello.txt"]
```

- ۱- `FROM` دستورالعمل Dockerfile برای مشخص کردن **Base Image** است.
- ۲- `ubuntu` آرگومان `FROM` است و مشخص می‌کند image پایه Ubuntu باشد.
- ۳- `COPY` دستورالعملی برای کپی کردن فایل از سیستم Host به داخل Image است.
- ۴- `hello.txt` فایل مبدا است که از Build Context خوانده می‌شود.
- ۵- `.` مقصد کپی داخل Image است؛ یعنی فایل در دایرکتوری کاری فعلی داخل Image قرار بگیرد.
- ۶- `CMD` دستور پیش‌فرضی است که هنگام اجرای Container اجرا می‌شود.
- ۷- `"cat"` برنامه‌ای است که باید داخل Container اجرا شود.
- ۸- `"hello.txt"` آرگومان دستور `cat` است و مشخص می‌کند محتوای این فایل نمایش داده شود.
