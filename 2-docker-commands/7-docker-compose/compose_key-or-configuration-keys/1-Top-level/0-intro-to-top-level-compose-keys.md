برای مقدمه‌ی **Top-level keys** اینو می‌تونم بگم:

ا-**Top-level keys** کلیدهایی هستند که در بالاترین سطح فایل `compose.yaml` قرار می‌گیرند و ساختار کلی پروژه‌ی Docker Compose را مشخص می‌کنند. یعنی قبل از اینکه وارد تنظیمات جزئی هر کانتینر یا سرویس شویم، با این کلیدها تعیین می‌کنیم پروژه چه بخش‌هایی داشته باشد.

مهم‌ترین Top-level keyها معمولاً این‌ها هستند:

`services`، `volumes`، `networks`، `configs` و `secrets`

مثلاً:

```
services:
  app:
    image: nginx

volumes:
  app-data:

networks:
  backend:

configs:
  app-config:

secrets:
  db-password:
```

در این ساختار، `services` برای تعریف سرویس‌هاست، `volumes` برای تعریف فضای ذخیره‌سازی، `networks` برای شبکه‌ها، `configs` برای تنظیمات و `secrets` برای اطلاعات حساس استفاده می‌شود.

نکته‌ی مهم: <mark>**Top-level یعنی این کلیدها مستقیماً از ابتدای فایل شروع می‌شوند و زیر کلید دیگری نیستند.**</mark>

## اینم بریم سراغه اینکه کدومشون کاربرد بیشتری دارند
برای استفاده‌ی روزمره، بین **Top-level keyها** معمولاً این ترتیب کاربرد رو داری:

- ا-`services` → **خیلی زیاد**؛ تقریباً همیشه باهاش کار داری چون همه‌ی سرویس‌ها داخلش تعریف می‌شن.
- ا-`volumes` → **زیاد**؛ وقتی دیتابیس، آپلود فایل یا داده‌ی ماندگار داری.
- ا-`networks` → **زیاد**؛ مخصوصاً در پروژه‌های چندسرویسی مثل `frontend + backend + database`.
- ا-`secrets` → **متوسط**؛ بیشتر در پروژه‌های production و حرفه‌ای برای اطلاعات حساس.
- ا-`configs` → **کمتر**؛ برای مدیریت فایل‌های config، بیشتر در سناریوهای حرفه‌ای‌تر.

پس برای یادگیری روزمره اول این سه‌تا رو خیلی خوب بلد باش:

`services` → `volumes` → `networks`

بعد برو سراغ `secrets` و `configs`.
