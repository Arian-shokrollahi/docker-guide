## دیدن اون نسخه ای از داکر که رویه سیستمتون نصب شده است
---

ا-`docker --version` فقط نسخه‌ی Docker نصب‌شده روی سیستم رو نشون می‌ده.

مثلاً:

```
docker --version
```

ممکنه خروجی شبیه این باشه:

```
Docker version 27.5.1, build 9f9e405
```

بررسی کوتاه:

`Docker version 27.5.1`

یعنی نسخه Docker نصب‌شده روی سیستم تو `27.5.1` هست.

`build 9f9e405`

یعنی شناسه‌ی Build مربوط به همون نسخه.

نکته مهم اینه که این دستور فقط برای چک کردن نسخه است و اطلاعات کامل درباره Docker Engine نمی‌ده.

برای اطلاعات بیشتر بعداً می‌ریم سراغ:

```
docker info
```

پس فعلاً اینو یادت بمونه:

```
docker --version
=
Check installed Docker version
```
